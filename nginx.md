# What is the difference between installed and running?
$ Installed means the web server's software code and configuration files are sitting on your hard drive, while running means the server is actively loaded into memory, listening for web traffic, and serving web pages.
# What is the difference between running and enabled?
$ Running refers to the current state of a program right now, while enabled refers to what will happen to the program automatically when the server boots up in the future.
# Why might a service work today but fail to start after a server reboot?
$ Service is disabled in the system startup settings, or because a required dependency like a network or database is not ready when the service tries to start.
