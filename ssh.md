## Understand SSH
# What is SSH?
Secure Shell is a network protocol used to safely connect and manage remote computer or server.
# Why SSH important to Cloud Engineers?
It provides a secure, encrypted mechanism to control systems remotely, automate tasks, and manage cloud assests.
# Which port does SSH normal use?
Port 22
# What is authentication?
Process of verifying who someone is.
# What is the difference between password authentication and SSH-key authentication? 
Password authentication – A human-readable text string that you memorize.
SSH-Key authentication - A pair of complex, mathematically linked cryptographic files.
# Where is your private key stored?
In the local computer
# Why must a private key never be committed to GitHub?
It grants absolute, unrestricted access to your servers and infrastructure, and GitHub repositories are continuously scanned by malicious actors.
